# Systemsäkerhet – hur bygger vi säkra system?

Systemsäkerhet kan ibland kännas som en djungel av begrepp, standarder och metoder. Men vad handlar det egentligen om?

I grunden handlar det om att förstå vad som kan gå fel i ett system, vilka konsekvenser det kan få och hur vi kan förhindra att någon kommer till skada.

Här har jag samlat korta artiklar där jag försöker förklara olika begrepp och principer inom systemsäkerhet på ett enkelt sätt.

Du kan bland annat läsa om [säkerhetsarkitektur](/system_safety/safety_architecture/), [säkerhetsmekanismer](/system_safety/safety_mechanism/), [fail-safe](/system_safety/fail_safe/), [fail-operational](/system_safety/fail_operational/) och [redundans](/system_safety/redundancy/).

**Tanken är inte att gå på djupet i varje ämne**, utan att ge en grundläggande förståelse. Tillräckligt för att kunna se hur saker hänger ihop och sedan själv söka vidare för den som vill fördjupa sig.
